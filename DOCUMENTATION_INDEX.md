## 📖 Reading Guide

### If You Want To...

#### **See the App Working**
1. Open terminal
2. Run: `npm install`
3. Run: `npm run dev`
4. Open: `http://localhost:5173`
5. Read: [QUICK_START.md](QUICK_START.md) while exploring

#### **Understand the Design**
1. Read: [PROJECT_COMPLETION.md](PROJECT_COMPLETION.md) for overview
2. Read: [UI_DESIGN_GUIDE.md](UI_DESIGN_GUIDE.md) for design system
3. Read: [DESIGN_OVERVIEW.md](DESIGN_OVERVIEW.md) for screen details
4. Reference: [index.css](src/index.css) for actual CSS variables

#### **Understand the Code**
1. Read: [IMPLEMENTATION_SUMMARY.md](IMPLEMENTATION_SUMMARY.md)
2. Check: `src/` folder structure
3. Review: Component files in `src/components/`
4. Examine: CSS files in `src/styles/` and `src/components/`

#### **Customize the Design**
1. Read: [UI_DESIGN_GUIDE.md](UI_DESIGN_GUIDE.md) for design tokens
2. Edit: CSS variables in [src/index.css](src/index.css)
3. Edit: Component content in `src/components/`
4. Edit: Styles in `src/components/screens.css`

#### **Deploy to Production**
1. Run: `npm run build`
2. Deploy: `dist/` folder to your hosting
3. Read: [README.md](README.md) for deployment notes
